## ADR-007 — BYOK for the LLM

Decided with Tri on 11–12/10.

- A user's own provider key is used **instead of ECA's key** for the turn's LLM
  steps (planner, retriever, synthesizer). ECA does not store it: the browser
  keeps it in localStorage and sends it in the `/chat` body each turn; the
  server holds it in memory for that request only.
- One adapter for every provider: `ChatOpenAI` + `base_url`, the way DeepSeek
  was already wired. No provider table in the backend. The frontend's preset
  list only prefills an endpoint.
- No dependency on OpenRouter; it is one preset among others.
- The connection check runs in the browser, straight to the provider, when the
  key is pasted. Metadata first (models.dev), then a single ping. No separate
  JSON probe.
- A graph role runs on the user's model only if the model can do what that role
  asks. A model that only reads and writes text still writes the answer.
- Not in this round: sending images to the model; localhost models (waits for
  a desktop build).

Chosen by K, not yet confirmed by Tri: the safety grader and the background
summarizer stay on ECA's key; a provider failure mid-turn falls back to ECA
with a notice; the preselected model is the cheapest of the five newest.

## UI rework (after Tri's test)

`ProviderDetailView.tsx`, top to bottom:

- API key first, with re-check and delete as icon buttons beside it, and one
  status line under it.
- Model is a dropdown filled from the provider's list, never typed. Two groups:
  models the catalog knows can chat (newest first), then everything else.
  Ids are shown without the `models/` prefix. A saved key lists its models on
  open. A typed model name exists only for a provider that publishes no list,
  under Advanced settings.
- "Use this API key" / "Dùng API key này" selects the key and closes the modal.
  Reopened, the screen shows "Đang sử dụng" with a way to stop.
- Endpoint moved under "Advanced settings" / "Cài đặt nâng cao", collapsed.
- Removed: capability chips, the storage notice, the old title and hint.

`SettingsContent.tsx`:

- The card in use is outlined and says "Đang sử dụng" with its model. It
  follows what will actually answer: a selected key that has been rejected
  shows ECA as in use.
- Real provider logos for 26 of 28 presets, from `@lobehub/icons-static-svg`
  1.95.1 (MIT), copied into `src/asset/provider-icons/` as one SVG per preset
  id. Painted as a CSS mask so they take the theme and hover colour. `n1n`,
  `openpaths` and `openai-compatible` have no mark in that set and keep a
  neutral icon. `providerIcons.test.ts` fails if a new preset has no logo.
- ECA's card uses the ECA logo at 1.5x. "OpenAI Compatible" moved to second.
